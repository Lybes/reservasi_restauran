# Reservasi Restaurant (Flutter)

Hasil konversi dari project Kotlin/Android `ReservasiRestaurantButton`.

## Cara menjalankan
1. Pastikan Flutter SDK terpasang (`flutter doctor`).
2. Di folder ini jalankan sekali untuk membuat folder platform (android/ios):
   flutter create . --org com.example --project-name reservasi_restaurant
3. flutter pub get
4. flutter run
